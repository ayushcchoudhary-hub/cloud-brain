# Sample wikis

Three small research wikis in the Karpathy "compiled wiki" shape: a `pages/`
folder of markdown, one `>` summary line under each title, `[[wikilinks]]`
between pages and a sources list at the end of each page.

The contributors are fictional people. Each folder's `contributor.json` sets the
name and location the server shows. The content was compiled from public
sources in November 2026 and will go out of date. It is demo data, not legal,
regulatory, medical or energy advice.
